`.claude/skills/`, and the module layout — so CLAUDE.md is *their own* spec, not an inherited
one, and challenging it is in scope.

Writes unusually self-critical review briefs: enumerates the specific invariants to judge
against, names their own possible overreach as a review question, and asks whether decisions
should have been deferred to a more specialised agent. Treat those as sincere questions, not
rhetorical ones — answering "yes, this was your call to make and it was wrong" is wanted.

Comfortable with Gradle/Kotlin internals. No need to explain what `api` vs `implementation`
means; go straight to the consequence.
